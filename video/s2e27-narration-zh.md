## 开场：逃走的鼓包

1. 一条无限长的直线上，有个高度为 1 的鼓包。
2. 让它往右滑。一步、十步、一百万步。
3. 它的能量从不改变，和原来一样大。
4. 现在随便在哪儿放个传感器。鼓包经过……
5. ……传感器跳一下，之后永远读 0。
6. 放一千个传感器，每一个最后都读 0。
7. 所有测量都说它没了。其实没有，它逃走了。
8. 今天：只问测量的收敛。

## 片头

1. 第二季，第二十七集。弱收敛。

## 达不到的最小值

1. 第 20 集：这里有界序列未必有收敛子列。
2. 取 F(x) = (‖x‖² − 1)² + Σ xₖ² / k²。
3. 沿着 e₁、e₂……F 掉成 1、¼、⅑……→ 0。
4. 可没有哪一点达到 0。最低点不见了。
5. 我们需要一种更弱的收敛。

## 弱收敛与 eₙ ⇀ 0

1. 每个 f 都有 f(xₙ) → f(x)，就叫 xₙ 弱收敛到 x。
2. 看 ℓ² 里的 eₙ。每个 f 是 ℓ² 里的一个探针 y。
3. f(eₙ) = yₙ，而 Σ yₖ² 有限，所以 yₙ → 0。
4. 于是 eₙ ⇀ 0，虽然每个 ‖eₙ‖ 都是 1。
5. 范数在极限处可以变小：‖x‖ ≤ lim inf ‖xₙ‖。
6. 弱极限唯一，弱收敛序列有界。

## 质量逃走的三条路

1. 质量可以从三条路逃走。
2. 平移：一块东西滑向无穷远。
3. 集中：它挤进一个点。
4. 振荡：sin(nx) 越摆越快。
5. 三种都保住了能量，三种都 ⇀ 0。
6. 可 sin²(nx) ⇀ ½，不是 0²。平方过不去。

## 盲人摸象（中文版）

1. 《大般涅槃经》里，几个盲人去摸一头象。
2. “其触牙者，即言象形如芦菔根……”
3. 每人只知道自己那根探针读到的东西。
4. 弱收敛也是这样：只凭所有探针的读数来判断。

## ℓ¹ 不一样

1. 在 ℓ¹ 里不行。探针 (1, 1, 1, …) 是允许的。
2. 它把每个 eₙ 都读成 1，读数永远不消失。
3. ℓ¹ 不自反，弱极限在那里什么也换不来。

## 弱*收敛与巴拿赫–阿劳格鲁

1. 弱*：泛函在每个 x 上都对得上，就算收敛。
2. 1/n 处的 δ ⇀* 0 处的 δ，虽然它们一直相距 2。
3. 巴拿赫–阿劳格鲁：对偶的单位球是弱*紧的。
4. 可分的 X 来证：把 x₁、x₂、x₃……排成一列。
5. 先挑子列在 x₁ 上稳定，再在 x₂ 上……
6. 对角线在每一处都稳定。又是康托尔的表格。

## 直接方法

1. 在自反空间里，有界就一定有弱极限。
2. 马祖尔：闭凸集留得住它的弱极限。
3. 所以凸的 F 在弱极限处只会变小。
4. 直接方法：一路下坡，取弱极限，完事。
5. G(x) = ‖x‖² − 2Σ xₖ / k 凸，最小值 −π²/6。
6. 最开始的 F 不凸，它的极限落得太高。
