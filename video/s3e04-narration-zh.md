《傅里叶就是对偶》的旁白，由 `src/s3e04/narration.ts` 生成，以该文件为准。每行是一条字幕。
内容来自 `lessons/s3/e04-fourier-is-duality.md`，按中文习惯重写，不是逐句翻译。
中文版多一场：《庄子·徐无鬼》的“鼓宫宫动，鼓角角动”。

## 开场：为什么是波？

1. 为什么拆信号，总是拆成波？
2. 手机每秒都要对音乐做上几千次。
3. 标准正交基有无数组，凭什么是这一组？
4. 把一个鼓包右移：变成一个新函数。
5. 把抛物线右移：又是一个新函数。
6. 把螺旋 e^(iωt) 右移：同一条螺旋，乘一个数。
7. 它是所有平移共同的特征向量。
8. 傅里叶分析，就是平移群的表示论。

## 标题

1. 第三季，第四集。傅里叶就是对偶。

## 平移想要什么：特征标

1. 平移成群：先移 a 再移 b，就是移 a + b。
2. 找那些每个平移都只缩放的函数。
3. 令 f(0) = 1，就有 f(x + y) = f(x) f(y)。
4. 这就是特征标：到单位圆的同态。
5. 在 ℤ/8 上：χₖ(j) = ωʲᵏ，指针每次走 k 步。

## 平移求和得正交

1. 把一个非平凡特征标在整个群上加起来。
2. 把和平移一下：它乘上了 χ(h) ≠ 1。
3. 可平移后还是同一个和，所以它是 0。
4. 特征标两两正交：n 个，正好一组基。
5. 傅里叶变换：就是这组基下的坐标。

## DFT 矩阵

1. 对 ℤ/n，把特征标排成矩阵的行。
2. 一格格小钟表的指针：DFT 矩阵。
3. 除以 √n 是酉矩阵：ℂⁿ 的一次旋转。
4. 在新基下，每个平移都是对角的。
5. 于是卷积变成了逐点相乘。

## FFT 蝴蝶

1. 把样本分成偶数位和奇数位。
2. 两个一半大小的 DFT，用蝴蝶拼起来。
3. 一直分下去：n log n 步，而不是 n² 步。
4. n = 2²⁰：一万亿步降到两千万步。

## 《庄子》鼓宫宫动（仅中文版）

1. 《庄子·徐无鬼》：调两张瑟，堂上一张，室内一张。
2. “鼓宫宫动，鼓角角动，音律同矣。”
3. 弹一个音，另一张瑟上只有同音的弦会动。
4. 傅里叶系数，就是信号和一个特征标的共振。

## 群与它的对偶

1. 特征标自己也成群：对偶群 Ĝ。
2. 就像 V 和 V*：向量和余向量。
3. ℤ/n 和它的对偶同构，但得先选定 ω。
4. 对偶的对偶，什么都不用选。
5. 圆 ↔ 整数，整数 ↔ 圆，ℝ ↔ ℝ。
6. 庞特里亚金：这类群都是对偶的对偶。

## ℝ、L² 与普朗歇尔

1. 在 ℝ 上，e^(2πiξx) 永不衰减，不在 L² 里。
2. 它和 δ 一样，就住在空间外面。
3. 对特征标求和，变成了积分。
4. 普朗歇尔：傅里叶变换在 L² 上是酉的。
5. 高斯函数装得进去，还变回它自己。

## 第一幕回顾

1. 域是向量空间：维数。
2. 交换群和算子都是模：若尔当标准形。
3. 群用矩阵来作用：迹。
4. 傅里叶就是对偶：对偶空间。
