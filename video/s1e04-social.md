**Thread** (4 posts):

1. `"Any property you can describe makes a set" sounds harmless. It broke the foundations of mathematics in 1901. 🧵`
2. `Take every set that doesn't contain itself and collect them into R. Is R in R? If it is, it isn't. If it isn't, it is. Russell wrote to Frege in 1902, just as Frege's arithmetic, built on that exact idea, was going to print.`
3. `The fix (Zermelo, then Fraenkel): you may only carve a smaller set out of one you already have. Carve Russell's set out of any set A and it lands outside A. The paradox becomes a theorem: there is no set of all sets.`
4. `Then build the numbers. Von Neumann: next(x) = x ∪ {x}. Zermelo: next(x) = {x}. Both satisfy Peano. Is 1 an element of 3? Yes for one, no for the other. So which is the real 3? Episode 4: <YouTube link>`
