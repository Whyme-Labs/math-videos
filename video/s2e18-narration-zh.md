## 开场：三根转得稳的轴

1. 把盒子旋着抛到空中。它会乱晃。
2. 可绕着三根轴中的一根转，它就转得很稳。
3. 每个刚体都有这三根轴：土豆、扳手、手机。
4. 而且三根轴总是互相垂直。
5. 第二个谜题：曲线 5x² + 4xy + 2y² = 1。
6. 一个斜着的椭圆。最长和最短的直径成 90°。
7. 两个问题背后，都是一个对称矩阵。
8. 今天：为什么对称就意味着互相垂直的轴。

## 特征向量不够用的时候

1. 特征向量：映射只做伸缩的方向。
2. 旋转一个都没有。错切只有一个。
3. 有的特征基很糟：(1, 0) 和 (100, 1)。
4. 几乎平行，拿来度量什么都不好用。
5. 有了内积，就要最好的：互相垂直的特征向量。

## 垂直的轴逼出对称

1. 假设 A 有一组互相垂直的单位特征向量。
2. 在这组基下，A 只是对角线上的一串伸缩。
3. 换回平常的坐标轴：A = QDQᵀ。
4. 沿对角线翻过来，一点不变：Aᵀ = A。
5. 所以对称是必要的。定理说：它也是充分的。

## 实特征值，垂直的特征向量

1. 对称就是 ⟨Au, v⟩ = ⟨u, Av⟩：A 可以挪到另一边。
2. 取特征向量 u 和 v，伸缩倍数是 λ 和 μ。
3. 把 A 挪过去：λ⟨u, v⟩ = μ⟨u, v⟩。
4. 如果 λ ≠ μ，那么 ⟨u, v⟩ = 0。只能垂直。
5. 在 ℂ 上用同一招，可知每个 λ 都是实数。

## 垂直平面不动

1. 关键的一步。取一支特征箭头 v。
2. 它的垂直平面：所有和 v 成直角的向量。
3. 对称映射把这个平面送回它自己。
4. 因为 ⟨Aw, v⟩ = ⟨w, Av⟩ = λ⟨w, v⟩ = 0。
5. 错切就不行，它的平面被掀歪了。
6. 所以剩下的部分，永远不会和 v 缠在一起。

## 一根根剥出来的证明

1. 证明就这么多。先找到一支特征箭头。
2. 把它分出去，剩下的仍然是对称的。
3. 在剩下的里面再找一支，再分出去。
4. 一直重复，直到没有空间。
5. 互相垂直的单位轴，每个维度一根。

## 斜椭圆

1. 回到那个斜椭圆。它的矩阵是 [5 2; 2 2]。
2. 伸缩倍数是 6 和 1，方向 (2, 1) 和 (1, −2)。
3. 果然互相垂直。
4. 转到这两根轴上：曲线变成 6X² + Y² = 1。
5. 交叉项没了。半轴是 1/√6 和 1。
6. 椭圆，就是透过对称映射看到的圆。

## 曾侯乙编钟（中文版）

1. 1978 年，湖北随州出土曾侯乙编钟，战国早期。
2. 钟身不是圆的，是两片瓦合成的“合瓦形”。
3. 敲正面中间是一个音，敲侧面是另一个音。
4. 一钟双音：两种振动各自独立，互不牵连。
5. 对称的钟体，把振动分成了两个“主方向”。

## 二阶导数判别法

1. 微积分里也是这样：f = x³ − 3xy + y³。
2. 平坦点在 (0, 0) 和 (1, 1)。各是什么？
3. 二阶导数排成一个对称矩阵：黑塞矩阵。
4. 在 (0, 0)，它的伸缩倍数是 3 和 −3。
5. 沿一根轴向上，沿另一根向下：鞍点。
6. 在 (1, 1)：3 和 9，都为正：一个碗。

## 伸缩过的影子之和

1. 换个说法：A 是一组伸缩过的影子之和。
2. 投影到每根轴上，乘以 λ，再加起来。
3. 对这个椭圆：A = 6 P₁ + 1 P₂。
4. 于是 A 的函数也有了意义：√A = √6 P₁ + P₂。
5. 量子力学的测量，用的正是这些影子。

## 片尾

1. 对称映射只做伸缩，沿着互相垂直的轴。
2. 这些轴可以一根一根剥出来。
3. 下一集：任何矩阵，对称与否。奇异值分解。
