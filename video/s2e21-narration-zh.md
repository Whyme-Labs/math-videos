## 范数的规矩

1. 范数是一种长度，守三条规矩。
2. 只有零的长度是零；x 加倍长度加倍；三角不等式。
3. 每个范数有一个单位球：菱形、圆盘、正方形。
4. 三角不等式成立，恰好当单位球是凸的。
5. 星形的“球”会破坏它，那就不是范数。

## ℓ¹、ℓ²、ℓ∞

1. 同样的规矩，在数列上给出一园子：ℓ¹、ℓ²、ℓ∞。
2. 对每个数列：峰值 ≤ 能量 ≤ 总量。
3. (1, ½, ⅓, …) 能量有限，总量无穷。
4. (1, 1, 1, …) 有界，能量却无穷。

## 不等价的范数

1. 把总量 1 平均摊到 n 个格子里。
2. 总量还是 1。能量是 1/√n，峰值是 1/n。
3. 两个范数等价：各自不超过另一个的 C 倍。
4. 对那些尖刺，峰值 ÷ 面积 = 2n²。没有 C 管用。

## 有限维里范数都等价

1. 在平面上，任何两个范数都等价。看为什么。
2. 任何范数都不超过普通长度的常数倍。
3. 另一边，看单位圆。
4. 单位圆有界又闭合，范数在上面取得最小值。
5. 这个最小值不是 0，它就是要找的常数。
6. 只有一步用到有限维：单位圆是紧的。

## 有界算子

1. 好的线性映射尊重“小”：‖Tx‖ ≤ C‖x‖。
2. 最小的 C 就是算子范数。对矩阵，就是 σ₁。
3. 有界和连续，原来是同一回事。
4. 求导就不行：xⁿ 峰值是 1，斜率却是 n。
5. 把陡峭也算进长度，它又有界了。
6. 有没有界，取决于映射和两边的范数。

## 一个矩阵，三个范数

1. 一个矩阵，三把尺子，三个算子范数。
2. A = [1 2; 3 4]。把每种单位球推过去。
3. 菱形尺：6。圆盘尺：5.46。正方形尺：7。
4. 一个映射有多大，要看你怎么量。

## 里斯引理

1. 单位球为什么永远不紧？里斯，1918 年。
2. 对任何闭的子空间，总有一个单位向量离它很远。
3. 至少相距 ½。把它加进子空间，再来一次。
4. 一串单位向量，两两至少相距 ½，没有尽头。
5. 只有在有限维里，单位球才是紧的。

## C[0, 1] 里的洞

1. 还有一道裂缝。一串斜坡越来越陡。
2. 按面积量，它们彼此越挤越近。
3. 可它们奔向的阶梯函数，并不连续。
4. 用面积范数，连续函数的空间有洞。
