2. `Step 1: code every formula as a number. With a toy code, "0 = 0" is 2¹·3³·5¹ = 270. Proofs become numbers too, so arithmetic can talk about its own proofs.`
3. `Step 2, the diagonal: build a sentence G that says "G is not provable." If the axioms proved G, they'd prove a falsehood. So they can't, which is what G says. G is true.`
4. `Add G as an axiom and the trick builds a new G. No consistent rulebook for arithmetic gets every truth, or proves its own consistency. Episode 15: <YouTube link>`
