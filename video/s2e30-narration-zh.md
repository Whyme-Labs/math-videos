## 开场：琴弦与谱定理

1. 拨一下吉他弦，你听到一个音。
2. 可它同时在整体振、对半振、三段振、四段振。
3. 每种形状都是正弦，各有频率：1、2、3、4……
4. 第 18 集：对称矩阵有互相垂直的特征向量。
5. 椭圆对准它的轴。这就是谱定理。
6. 弦有无穷多个振型。谱定理还成立吗？
7. 不一定：有的算子一个特征向量都没有。

## 有限维的证明为何失效

1. 有限维的证明：在单位球面上让 ⟨Tx, x⟩ 最大。
2. 最大点就是第一个特征向量。剥掉它，再来一遍。
3. 试试 L²[0, 1] 上“乘以 x”这个算子。
4. 鼓包挤向 x = 1，⟨Mf, f⟩ 爬向 1。
5. 可没有哪个函数到得了。球面不紧。

## 紧算子

1. 紧算子：把有界序列变成有极限点的序列。
2. 例子：diag(1, ½, ⅓, …) 把单位球压扁。
3. 它的轴越来越短，像几乎有限维。
4. 恒等算子不紧：e₁、e₂……两两相距 √2。
5. 紧算子是有限秩算子的极限。
6. 它把弱极限变成真极限：Teₙ → 0。

## 紧算子的谱定理

1. 谱定理：紧的自伴算子，有一组特征基。
2. 这下求最大的序列管用了：Txₙ 有极限。
3. 于是第一个特征向量存在。剥掉它，再来。
4. 特征值从两边向 0 靠拢。
5. 在 [−ε, ε] 之外，只有有限个。
6. Tx = Σ λₖ ⟨x, uₖ⟩ uₖ：第 18 集，无限长版。

## 朱载堉十二平均律（中文版）

1. 明代朱载堉，1584 年写成《律学新说》。
2. 他把 2 的十二次方根算到二十五位：1.059463……
3. 十二个半音，弦长按这个比一级级缩短。
4. 弦的频率排成离散的一串，正是今天讲的谱。

## 弗雷德霍姆二择一

1. 弗雷德霍姆：K 紧，解 u − λKu = f。
2. 要么对每个 f 都恰好有一个解……
3. ……要么 u − λKu = 0 有解，而 f 必须与它正交。
4. 例子：K(x, y) = xy，只在 λ = 3 时出问题。
5. 秩–零化度定理，在无穷维里被救了回来。

## 振动的弦

1. 回到弦：−u″ = λu，且 u(0) = u(1) = 0。
2. −d²/dx² 连有界都不是，可它的逆 G 是紧的。
3. G 的特征函数是 sin(nπx)，特征值 1/(n²π²)。
4. 取倒数：频率 nπ，一串离散的阶梯通向无穷。
5. G 的迹是 1/6，于是又得到 Σ 1/n² = π²/6。

## 沃尔泰拉算子

1. 自伴很重要。沃尔泰拉算子：(Vf)(x) = ∫₀ˣ f。
2. V 是紧的，却一个特征值都没有。
3. ‖Vⁿ‖ ≤ 1/n!：处处压小，却不固定任何方向。
