## 开场

1. 我们描述了数怎么表现。可数字二本身，到底是什么？
2. 从最简单的东西开始造：一个空盒子，叫它零。老子说“有生于无”，我们真的从无开始。
3. 把空盒子放进一个新盒子。里面有一样东西，叫它一。
4. 再拿一个盒子，把前面两个都装进去。里面有两样东西，叫它二。
5. 盒子套盒子，从无到有。但先得定好规矩：什么样的盒子才允许存在。

## 罗素悖论

1. 康托尔那个时代的想法是：只要能说出一个性质，就有一个集合。
2. 偶数的集合，还有“所有集合的集合”，它甚至得装下自己。
3. 现在取“不包含自己”这个性质，把所有这样的集合收进 R。
4. R 在不在 R 里面？如果在，它就不该在；如果不在，它就该在。
5. 罗素在 1901 年前后发现了它。1902 年他写信给弗雷格，而弗雷格的算术大厦，正建在这个想法上。

## 《墨经》（中文版独有）

1. 两千多年前，墨家也碰到过这种自己绕住自己的话。
2. 《墨经》说：“以言为尽悖，悖。说在其言。”断言所有的话都是假的，这句话本身就站不住。

## ZF：安全的造集合规则

1. 解决办法是：不许把“所有满足某性质的东西”一股脑儿收成集合。
2. 只能从已有的集合里切出一部分，或者用几样固定的工具来造。
3. 这套规矩叫 ZF，取自策梅洛和弗兰克尔的名字。
4. 从任何一个盒子里切出罗素集合，它都会落在盒子外面。悖论变成了定理：不存在“所有集合的集合”。

## 冯·诺伊曼的数

1. 现在开始造。零就是空集。
2. 集合 x 的下一个，是 x 再加上 x 本身：x 并上 {x}。
3. 所以一装着零；二装着零和一；三装着零、一、二。
4. 每个数，都是它前面所有数的集合，所以三恰好有三个元素。
5. 把它们全收齐，皮亚诺的五条规则都成立。这就是自然数，从无中造出来。

## 策梅洛的数

1. 1908 年，策梅洛用了另一种“下一个”：只是把 x 再装进一个盒子。
2. 零、装着零的盒子、再装着它的盒子，一层层下去。
3. 两种造法都满足皮亚诺的规则。那么，一是不是三的元素？
4. 冯·诺伊曼的三说：是。策梅洛的三说：不是。

## 哪个才是真正的 3？

1. 那哪一个才是真正的三？1965 年，哲学家贝纳塞拉夫正是这样问的。
2. 戴德金定理把两条链一一对上，所以它们的算术完全一样。
3. 三重要的是它站在哪里：在二之后，在四之前。数，就是它所做的事。
