## 开场：挤向 eˣ 的多项式，和 √2

1. 一串多项式：1，然后 1 + x，然后 1 + x + x²/2……
2. 每次多加一项 xⁿ/n!。
3. 在 [0, 1] 上，很快就相差不到一笔的粗细。
4. 它们正奔向某个东西：eˣ。
5. 可 eˣ 不是多项式。
6. 只看多项式的话，它们挤向一个洞。
7. 又是第一季：1.4、1.41、1.414 挤向 √2。
8. 今天来填函数空间里的洞。

## 片头

1. 第二季，第二十三集。巴拿赫空间。

## 柯西序列

1. 彼此越挤越近的一串：柯西序列。
2. 过了某一项，任意两项都比 ε 还近。
3. 收敛的序列都是柯西序列。
4. 完备是反过来：挤在一起，就一定有目标。
5. 完备的赋范空间，叫巴拿赫空间。

## 哪些空间是完备的

1. 哪些空间是完备的？
2. 所有有限维空间；ℓᵖ；用峰值范数的 C[0, 1]。
3. 多项式不是：缺了 eˣ。
4. 有限长的数列不是：缺了 (1, ½, ¼, …)。
5. 用面积范数的 C[0, 1] 不是：缺了阶梯函数。

## ℓ² 为什么完备

1. ℓ² 为什么完备？取一串数列组成的柯西序列。
2. 每个坐标单独看，都是一串数的柯西序列。
3. ℝ 是完备的，所以每个坐标都有极限。
4. 这些极限组成数列 x，而 x 在 ℓ² 里。
5. 那串数列收敛到 x。ℓ² 继承了 ℝ 的完备。

## 完备化

1. 任何赋范空间都能完备化，做法和造 ℝ 一样。
2. 新的点是柯西序列，彼此靠拢的算同一个。
3. 多项式完备化成所有连续函数。
4. 有限数列完备化成 ℓᵖ。
5. 按面积量的连续函数，完备化成 L¹。

## 级数需要完备

1. 为什么在乎？无穷和需要完备。
2. 如果各项长度加起来有限，和就该存在。
3. 在巴拿赫空间里，它总存在。
4. 于是 e₁、e₂……成了 ℓ² 真正的基：用无穷和。
5. 但不是 ℓ∞ 的基：(1, 1, 1, …) 永远差着 1。

## 祖冲之的盈数与朒数（中文版）

1. 《隋书·律历志》记载祖冲之算圆周率。
2. 盈数三丈一尺四寸一分五厘九毫二秒七忽，
3. 朒数三丈一尺四寸一分五厘九毫二秒六忽。
4. 上下两个界，夹出一个数：这就是完备的样子。

## 压缩映射定理

1. 回报来了：巴拿赫，1922 年。
2. 压缩映射：把任意两点拉近，倍数 q < 1。
3. 解 x = cos x：随便从哪开始，一直取余弦。
4. 步子按几何级数缩小，所以迭代是柯西序列。
5. 空间完备，所以落在某处：0.739……
6. 恰好一个不动点，误差像 qⁿ 一样下降。

## 皮卡迭代与 PageRank

1. 微分方程也一样：y′ = y，y(0) = 1。
2. 改写成 y = 1 + ∫ y，然后迭代。
3. 1，然后 1 + t，然后 1 + t + t²/2……
4. 正是开头那串多项式：皮卡迭代落在 eᵗ 上。
5. PageRank 也是一个压缩映射。
