## 开场：会发散的傅里叶级数

1. 1807 年：傅里叶说，任何函数都是波的和。
2. 光滑的函数，部分和会一步步贴上去。
3. 每个连续函数，应该也一样吧？
4. 1873 年：杜布瓦-雷蒙造出一个在 0 处发散的。
5. 一层又一层的波纹，每层都手工调好。
6. 1927 年：巴拿赫和施泰因豪斯几行就证明了。
7. 他们根本没把那个坏函数写出来。
8. 秘诀是完备性。今天讲由它而来的三个定理。

1. 第二季，第二十六集。三大定理。

## 每点有界还不够

1. 一族映射，在每一点上都有界。
2. 它们一定整体有界吗？不一定。
3. 这些鼓包在每个 x 处都趋于 0，峰却像 n 一样长。
4. 有限数列上的线性映射：fₙ(x) = n·xₙ。
5. 每点有界，‖fₙ‖ 却是 n。这个空间有洞。

## 贝尔定理

1. 贝尔定理：完备空间不是一堆尘土拼成的。
2. 取可数个薄薄的集合：直线、点、康托尔尘。
3. 挑一个圆盘，避开第一个。
4. 在里面挑个更小的，避开第二个。
5. 圆心是柯西序列，所以落到一个点上。
6. 这个点躲开了所有薄集。在 ℚ 里，它是个洞。

## 庖丁解牛（中文版）

1. 《庄子》里，庖丁的刀用了十九年还像新的。
2. “彼节者有间，而刀刃者无厚。”
3. “以无厚入有间，恢恢乎其于游刃必有余地矣。”
4. 薄集再多也挤不满完备空间，总有余地。

## 一致有界原理

1. 一致有界原理：每点的界，会变成一个总的界。
2. 按界把点分组：Fₙ 是所有 ‖Tx‖ ≤ n 的地方。
3. 这些 Fₙ 盖住了空间，其中一个装得下一个球。
4. 把这个球平移、缩放：每个 ‖T‖ ≤ 2N / r。
5. 范数无界？那就有某个 x 也无界。

## 开映射定理

1. 开映射：满的有界映射会把球撑开。
2. X 的单位球的像里，装得下 Y 的一整个球。
3. 要打中目标 y，每步把误差减半。
4. 这些步子是一个级数，完备性把它加起来。
5. 所以有界的双射，逆也有界。

## 闭图像定理

1. 闭图像：如果 (x, Tx) 的极限还在图像上……
2. ……那么在巴拿赫空间之间，T 就有界。
3. 看用峰值范数的 d/dx：xⁿ 一直是 1。
4. 它在 1 处的斜率是 n。无界，图像却是闭的。
5. 不矛盾：用峰值范数的 C¹ 不完备。

## 发散的傅里叶级数

1. 回到傅里叶。Sₙ f(0) = ∫ f·Dₙ。
2. Dₙ 是狄利克雷核，n 越大越高。
3. f ↦ Sₙ f(0) 的范数，就是 |Dₙ| 下的面积。
4. 这些面积像 (4/π²) ln n 一样长，慢，但不停。
5. 范数无界、空间完备：某个 f 在 0 处发散。
6. 而且大多数连续函数都这样。我们一个也没造。

## 没有可数的哈默尔基

1. 再来一个：哈默尔基。假设 b₁、b₂……就够用。
2. 每个张成 Fₙ 都是闭的，薄得像纸。
3. 可数个这样的薄片，盖不满巴拿赫空间。
