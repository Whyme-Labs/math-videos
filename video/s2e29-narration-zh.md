## 纯音是标准正交的

1. 纯音是 eⁱⁿˣ，每个整数 n 一个。
2. 两个不同的纯音相乘再取平均，得 0。
3. 正的面积和负的面积正好抵消。
4. 所以纯音是标准正交的。配方里的一项是 ⟨f, eₙ⟩。
5. 部分和 Sₙ f，就是投影到前几个纯音上。

## 按能量收敛，帕塞瓦尔

1. 把方波投影到越来越多的纯音上。
2. 剩下的能量：0.19、0.10、0.07、0.04……
3. 它趋于 0。对每个 f，Sₙ f 都在 L² 里趋于 f。
4. 帕塞瓦尔：声音的能量，等于各纯音能量之和。
5. 所以傅里叶映射 L² → ℓ² 保长度、保角度。
6. 方波：1 = (8/π²)(1 + 1/9 + 1/25 + …)。
7. 所以 1 + 1/9 + 1/25 + … = π²/8，Σ 1/n² = π²/6。

## 吉布斯过冲

1. 可逐点看，跳跃附近的过冲永远不走。
2. N = 9、49、199：峰值都在 1.179 附近。
3. 它越来越窄，带的能量趋于 0。
4. 按能量算傅里叶是对的；逐点只能几乎处处。

## 古琴十三徽（中文版）

1. 古琴有十三徽。嵇康《琴赋》：“徽以钟山之玉。”
2. 手指轻点徽位再拨弦，弹出的是泛音。
3. 点在一半是二倍频，点在三分之一是三倍频。
4. 徽位就是 sin(nx) 的节点。弦音是纯音的叠加。

## 求导是对角的

1. 傅里叶为什么在乎？他想解热传导方程。
2. d/dx eⁱⁿˣ = in·eⁱⁿˣ。每个纯音都是特征向量。
3. 在这组基下，d/dx 是对角的：…, −i, 0, i, 2i, …
4. 于是 uₜ = uₓₓ 拆成每个纯音一个简单方程。
5. 第 n 个纯音按 e⁻ⁿ²ᵗ 衰减，高音先消失。
6. 一个热环上，尖角最先被磨圆。

## 别的标准正交基

1. 傅里叶基只是众多基里的一组。
2. 对 1, x, x² 正交化，得到勒让德：x² − ⅓……
3. 埃尔米特函数：量子谐振子自己的状态。
4. 哈尔小波：一块块方波，信号跳的地方就放大去看。
5. 每组基，各自把一个算子对角化。

2. 能量守恒，求导变成乘法。
