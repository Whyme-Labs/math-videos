## 开场：分子的指纹

1. 一个水分子：三个原子，九种运动方式。
2. 三种是平移，三种是转动，三种是真振动。
3. 化学家不解方程，就能先把这三种分好类。
4. 两种保持镜面对称，一种把它翻过来。
5. 他们看的是一张小表，里面都是 1 和 −1。
6. 每个群都有这样一张表：它的指纹。
7. 每个对称只记一个数：矩阵的迹。
8. 一个数，怎么能知道这么多？

## 标题

1. 第三季，第三集。表示论。

## 对称变成矩阵

1. 正方形有 8 个对称，每个都移动整个平面。
2. 转四分之一圈：r = [0 −1; 1 0]。
3. 沿 x 轴翻转：s = [1 0; 0 −1]。
4. 对称接着对称做，就是矩阵相乘。
5. 表示：把每个 g 变成一个矩阵 ρ(g)。

## S₃ 置换三根轴：1 + 2

1. S₃ 置换三根坐标轴：一个 3 × 3 表示。
2. 可是过 (1, 1, 1) 的那条线从来不动。
3. 平面 x + y + z = 0 也被带回自己。
4. 换到这组基，每个矩阵都分块：1 + 2。
5. 不可约：再也分不出不变子空间。
6. 目标：把每个表示拆成不可约的块。

## 马施克：把内积平均

1. 总能拆吗？先随便取一个歪的椭圆。
2. 用 6 个对称把它挪一遍，全加起来。
3. 平均出来是个圆，哪个对称都动不了它。
4. 于是不变直线的垂线，也是不变的。
5. 马施克定理：有限群的表示，总能拆开。

## 舒尔引理

1. 舒尔引理：取一个和每个 ρ(g) 交换的映射。
2. 它的核和像，都是不变子空间。
3. 不可约表示之间：要么是零，要么是同构。
4. 从一个不可约表示到自己：只能是 λI。

## 特征标和特征标表

1. 矩阵随基而变，迹不变。
2. 特征标：χ(g) = tr ρ(g)，每个对称一个数。
3. S₃ 有三个不可约表示：平凡、符号、二维的。
4. 它们的特征标排成一张 3 × 3 的表。
5. 各行两两正交，像互相垂直的箭头。
6. 置换表示投影到各行：1、0、1。

## 《营造法式》格子门（仅中文版）

1. 北宋李诫《营造法式》，画下了格子门的格眼。
2. “四斜毬文”：转四分之一圈或翻过来，花样不变。
3. 这八个对称，正是正方形的群 D₄。
4. 每个对称都是平面的线性变换：一个表示。

## 水分子的三种振动

1. 回到水分子：它的群有 4 个对称。
2. 数每个对称下不动的原子：一个特征标。
3. 减去平移和转动，再投影到各行上。
4. 振动就出来了：两种对称，一种不对称。
5. 没解任何运动方程，只用了迹。
