3. `Cantor: a real number is where a swarm of fractions is heading. 1, 1.4, 1.41, … and 3/2, 17/12, 577/408 close in on the same spot, so glue them into one class. Multiply term by term and √2 · √2 is exactly 2.`
4. `A cut is a set of fractions; a Cantor real is a class of sequences. No number is literally the same in both. But both are complete ordered fields, and any two of those match up exactly. Built twice, described once. Episode 8: <YouTube link>`
