## 开场：随机分数与康托尔集

1. 在 0 到 1 之间完全随机地挑一个数。
2. 它是分数的机会有多大？
3. 分数到处都是，往哪里放大都密密麻麻。
4. 机会是零。不是很小，是零。
5. 更怪的：把 [0, 1] 中间的三分之一挖掉。
6. 每一段再挖掉中间的三分之一，一直挖下去。
7. 总共挖掉长度 1，剩下的点却和 ℝ 一样多。
8. 数个数和量大小，是两个不同的问题。

## 狄利克雷函数难倒黎曼

1. 黎曼积分把横轴切成一条条窄带。
2. 狄利克雷函数：分数处是 1，其余是 0。
3. 每条窄带再窄，两种点都有。上和 1，下和 0。
4. 没有积分。可它是一串积分为 0 的函数的极限。
5. 黎曼积分经不起取极限。

## 大小该是什么

1. 那“大小”该是什么？区间保留它的长度。
2. 把集合平移，大小不变。
3. 可数多块互不相交的部分：大小相加。
4. 要可数，因为极限是一步一步取的。

## 分数的大小是零

1. 现在看分数。把它们排成一列：q₁, q₂, q₃, …
2. 用长 ε/2 的区间盖住 q₁。
3. q₂ 用 ε/4，q₃ 用 ε/8，依此类推。
4. 总长不超过 ε，ε 要多小都行。
5. 所以分数的大小是零。

## 康托尔集

1. 康托尔集：2ⁿ 段，每段长 3⁻ⁿ。
2. 挖掉的：⅓ + 2/9 + 4/27 + … = 1。
3. 剩下的：三进制里只用 0 和 2 写的数。
4. 把每个 2 换成 1：每个二进制数都出现了。
5. 大小是零，点却和 [0, 1] 一样多。

## 量不了的集合

1. 每个集合都能给个大小吗？不能。
2. 如果 x − y 是分数，就说 x 和 y 是朋友。
3. 每个朋友圈里挑一个人，组成集合 V。
4. 把 V 平移 [−1, 1] 里的每个分数：互不相交的副本。
5. 副本盖住 [0, 1]，又装进 [−1, 2]：大小定不了。

## 曹冲称象（中文版）

1. 《三国志》记载，曹冲称象。
2. 大象太重，秤称不了。
3. 把象牵上船，刻下水痕；换成石头，装到同一道水痕。
4. 石头一块块称，加起来就是象重：换个切法来量。

## 切高度

1. 勒贝格的想法：切高度，不切横轴。
2. 像数硬币：先按面值分堆，再数每堆。
3. 对每个高度 t，量出 f 高于 t 的地方有多大。
4. 把所有高度加起来。对 x²，得到 ⅓。
5. 狄利克雷函数：1 × 分数的大小 = 0。
6. 现在极限和积分可以交换了。

## 概率就是测度

1. 概率论就建立在这上面。柯尔莫哥洛夫，1933 年。
2. 事件是可测集，概率是它的大小。
3. 随机取到分数：概率为 0，却可能发生。
4. 期望值就是一个积分。
