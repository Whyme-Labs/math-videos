## 开场

1. 二分之一和四分之二，是同一个东西吗？
2. 论多少，是。把一个叠到另一个上，涂色的部分正好重合。
3. 论写法，不是。数对 (1, 2) 和 (2, 4) 是两个不同的数对。
4. 钟表也是这样：十五点和三点，指针指着同一个位置。
5. 本来不同的东西，为了某个目的被当成一样。今天学的，就是怎么当才不出错。

## 关系与三条性质

1. 先说关系。关系就是一组数对，记下谁和谁相关。
2. 自反：每个东西都和自己相关。
3. 对称：a 和 b 相关，b 就和 a 相关。
4. 传递：a 和 b 相关，b 和 c 相关，a 就和 c 相关。
5. 三条都满足，就叫等价关系。这里的例子是：除以三，余数相同。

## “接近”没有传递性

1. 有些关系看着像“一样”，其实不行。比如两个数相差小于一，就算“接近”。
2. 零接近 0.6，0.6 接近 1.2，可零和 1.2 并不接近。
3. 小差距会累加，所以“接近”没有传递性，不能拿来把东西粘在一起。

## 分团：等价类与商集

1. 换一个真正的等价关系：除以十二，余数相同。
2. 相关的数聚到一起，成为一团。每一团叫一个等价类。
3. 再把每一团当成一个新的点。十二团，十二个点：一个钟面。
4. 十五和三在同一团里，所以在钟面上，它们相等。
5. 所有团组成的集合，叫商集。新世界里的相等，就是旧世界里的相关。

## 《孙子算经》物不知数（中文版独有）

1. 《孙子算经》里有一道“物不知数”：今有物不知其数，三三数之剩二，五五数之剩三，七七数之剩二，问物几何？
2. 用今天的话说，这个数同时属于三个等价类：除以三余二，除以五余三，除以七余二。
3. 书中答：二十三。南宋秦九韶给出了一般解法，这个结果今天叫“中国剩余定理”。

## 要么相同，要么不交：划分

1. 两团能不能只重叠一部分？假设 x 既在 a 的团里，也在 b 的团里。
2. 那么 a 和 x 相关，x 和 b 相关，所以 a 和 b 相关。其实本来就是同一团。
3. 所以两团要么完全相同，要么毫不相交。它们把集合切成小块，每个元素恰好在一块里，这叫划分。

## 良定义

1. 在钟面上做加法：从每一团里随便挑一个成员，相加，看结果落在哪一团。
2. 九加五等于十四，落在二那一团。
3. 换别的成员：二十一加十七等于三十八，还是同一团。加法过关。
4. 再试试“二的 n 次方”。零和十二在同一团里。
5. 二的零次方是一，二的十二次方是 4096，除以十二余四。落在不同的团，这条规则不成立。
6. 团上的每条规则都要过这一关。过了关的，叫“良定义”。

## 分数就是等价类

1. 回到分数。规定 p 乘 s 等于 q 乘 r 时，数对 (p, q) 和 (r, s) 算一样。
2. (1, 2) 这一团里有 (2, 4)、(3, 6) 等等，全在一条直线上。
3. 这一整团，就是分数二分之一。二分之一等于四分之二，因为它们在同一团里。
4. 要是允许零比零，它和每个数对都相关，所有的团会粘成一团。这就是分母不能为零的原因。

## 整套做法

1. 这就是整套做法：原始的描述，一条“算一样”的规则，分成团，再检查每个运算。
2. 接下来就用它造整数和分数，以后造实数，还有更多。
