## 冷开场：(1, i) 的长度是零

1. 1932 年，柏林。冯·诺伊曼用向量写量子力学。
2. 状态是一个复数向量，比如 (1, i)。
3. 它的长度给出概率。那就量一量。
4. 用上一集的办法：对应项相乘再相加。
5. 1·1 + i·i，就是 1 + (−1)。等于零。
6. 一支非零的箭头，长度是零。
7. 再试 (1, 2i)：1 + (−4) = −3。负的。
8. 今天：一个字母上加一道横，全部修好。

## 复数上没有正定的双线性型

1. 换个更巧的公式，两个插槽都线性，行吗？
2. 假设某支箭头 v 的 B(v, v) 是正的。
3. 把 v 转四分之一圈：乘以 i。
4. 两个插槽各提出一个 i。i · i = −1。
5. 于是 B(iv, iv) 是负的。这种公式不存在。

## 为什么要那道横

1. 看一个复数 z，在它的圆上。
2. z · z 转得快一倍，实部正负乱跳。
3. 把 z 沿实轴翻过去：这就是它的共轭。
4. 共轭乘 z，一点也不转，停在 |z|²。
5. 共轭抵掉了转动，只留下大小。

## 复内积

1. 那就在相乘之前，给第二个插槽取共轭。
2. 第一条：对第一个插槽线性。
3. 第二条：两个插槽对调，得到共轭。
4. 第三条：⟨v, v⟩ 是正的实数。
5. 现在 (1, i)：1·1 + i·(−i) = 1 + 1 = 2。
6. 把 ℂ² 摊成 ℝ⁴：(1, 0, 0, 1)。长度平方也是 2。

## 酉映射

1. 哪些映射保持这种长度？酉映射。
2. 每个坐标住在自己的复平面里。
3. 最简单的酉映射：让每个坐标在圆上转。
4. 长度变不了：每个坐标只是在转。
5. 换一组基，矩阵里填满了数。
6. 可它还是同样的转动，只是换了角度看。

## 特征值在单位圆上

1. 它的特征值一定在单位圆上。看为什么。
2. 设 Uv = λv。U 保持长度，‖Uv‖ = ‖v‖。
3. 把 λ 从两个插槽提出来：其中一个带共轭。
4. 所以 |λ|² = 1：λ 在单位圆上。
5. 没有那道横，这里只会得到 λ²，什么也证明不了。

## 矩阵世界

1. 复平面上有三类特别的数。
2. 实数：直线。厄米矩阵：特征值是实数。
3. 模为 1 的数：单位圆。酉矩阵住在这里。
4. 正数：射线。正定矩阵。

## 傅里叶变换是酉的

1. 压轴：把一段声音拆成各个频率。
2. 离散傅里叶变换用一个矩阵做到这件事。
3. 除以 √n 之后，这个矩阵是酉的。
4. 所以能量在时间上和在频率上一样多。
5. 反着变回去，只要共轭转置。
6. 每个音频文件、每通电话都靠它。
