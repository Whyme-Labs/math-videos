## 开场：信不过的测量

1. 量函数的工具：某点的值、斜率、面积。
2. 每个都是线性的：把函数变成一个数。
3. 这是 0 处一个窄窄的帐篷，面积 1/200。
4. 再窄：1/2000。还要窄，面积趋于 0。
5. 按面积量，这些帐篷缩成了没有。
6. 可“0 处的值”每次都读 1。
7. 冰块上读出 100° 的温度计，不算温度计。
8. 今天：只留下信得过的测量。

## 片头

1. 第二季，第二十四集。连续对偶。

## 不连续的线性泛函

1. 上篇的对偶，装着所有线性测量。
2. 在有限维里，它们每一个都是连续的。
3. 在无限维里，怪物出现了：f(x) = Σ k·xₖ。
4. 每个 eₙ 长度是 1，f(eₙ) 却是 n。
5. 输入差一点，输出差很多。没法用。

## 连续对偶与它的范数

1. 连续对偶 X* 只留下有界的那些。
2. 一个泛函的大小：它在单位球上最大的读数。
3. 想象它的等值线向外推，直到碰到单位球。
4. X* 永远是完备的，就算 X 不是。
5. 它的完备来自数本身，不是来自 X。

## 赫尔德不等式与对偶球

1. ℓᵖ 有哪些测量？赫尔德不等式给出答案。
2. Σ |xₖyₖ| ≤ ‖x‖ₚ ‖y‖ᵣ，其中 1/p + 1/r = 1。
3. 于是 ℓʳ 里每个 y 都能量 ℓᵖ。
4. 对偶的单位球：菱形的搭档是正方形。
5. 圆盘的搭档是它自己：p = r = 2。
6. p = 3 配 r = 3/2。一个变胖，另一个就变瘦。

## ℓᵖ 的对偶

1. 其实，1 ≤ p < ∞ 时，(ℓᵖ)* 正好是 ℓʳ。
2. 证明在 e₁、e₂……上试一遍，再靠稠密补全。
3. 有限数列在 ℓᵖ 里稠密，这是关键。
4. 在 ℓ∞ 里不稠密：(1, 1, 1, …) 永远差着 1。
5. 所以 (ℓ∞)* 比 ℓ¹ 严格大。

## 新莽铜卡尺（中文版）

1. 新莽铜卡尺，铭文“始建国元年正月癸酉朔日制”。
2. 一边是固定的爪，一边是能滑动的爪。
3. 东西厚一点点，读数就只变一点点。
4. 靠得住的量具，就是连续的测量。

## C[0, 1] 的对偶

1. 那用峰值范数的 C[0, 1]，有哪些测量？
2. 有的读一个点的值：δₜ(f) = f(t)。
3. 有的带权平均：∫ f g。
4. 它们全都是 [0, 1] 上的测度。又是里斯。

## 点值连续吗

1. 某一点的值信得过吗？要看情况。
2. 用峰值范数：|f(a)| ≤ ‖f‖∞。信得过。
3. 用面积范数，那些帐篷就把它弄坏了。
4. 在 L¹ 里，单独一点根本没有定义。

## 二次对偶与自反

1. 再来量这些测量：X**。
2. 每个 x 给出一个：f ↦ f(x)。这就是 J。
3. 如果 J 盖满整个 X**，X 就叫自反的。
4. 1 < p < ∞ 的 ℓᵖ：是。单位球是圆润的。
5. ℓ¹：不是。ℓ∞ 里不可数多个 0–1 数列，两两相距 1。
6. C[0, 1]：不是。它的点值测量两两相距 2。
