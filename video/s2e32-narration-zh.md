## 开场：搅咖啡

1. 往咖啡里倒奶，搅一下。漩涡一片混乱。
2. 两滴挨得极近的奶，最后跑到杯子两头。
3. 可搅拌不会凭空多出或少掉咖啡。
4. 每块区域被拉被挤，面积都不变。
5. 庞加莱：几乎每滴奶都会回到起点附近。
6. 奶还可能散得均匀无比。
7. 库普曼：别追着奶滴跑，去追测量值。
8. 点上的混沌，变成函数上的线性映射。

## 片头

1. 第二季，第三十二集。线性代数遇上混沌。

## 倍增映射

1. 倍增映射：x ↦ 2x mod 1。
2. 写成二进制，它只是删掉第一位。
3. 每走一步，数字整体左移一位。
4. 前 50 位相同的两个点，50 步后就分道扬镳。
5. 完全确定，却无法预测。那就问平均。

## 保测映射

1. 保测：对每个集合 A，μ(T⁻¹A) = μ(A)。
2. 转动 α：弧平移一下，长度不变。
3. 倍增：一段弧的原像是两段半弧，总长不变。
4. 正像可以变大，原像保持测度。
5. 猫映射 (2x + y, x + y)：行列式 1，面积不变。
6. 它一个方向拉长 2.618 倍，另一个压到 0.382。

## 庞加莱回归

1. 庞加莱回归：A 里几乎每个点都会回来。
2. 设 B 是 A 里永远不回来的点。
3. B、T⁻¹B、T⁻²B……两两不交，一样大。
4. 无穷多块一样大的塞进测度 1，只能是 0。
5. 所以 μ(B) = 0。奶滴会回来。

## 十九岁为一章（中文版）

1. 《周髀算经》：“十九岁为一章”，一章七闰。
2. 一年约 12.368 个朔望月，不是整数。
3. 每年月相错开 0.368 圈：就是圆上的转动。
4. 十九年后几乎回到原处：这就是回归。

## 库普曼算子

1. 库普曼，1931：Uf = f ∘ T，下一步的测量值。
2. 不管 T 多狂野，U 都是线性的。
3. T 保测，U 就是等距：‖Uf‖ = ‖f‖。
4. 倍增把每个纯音 eₖ 送到 e₂ₖ。
5. 奇数纯音永远打不到：等距，却不满。
6. 第 31 集的右移，藏在混沌里。

## 遍历与混合即谱

1. U1 = 1：常数永远不变。
2. 遍历：不变集要么零测，要么满测。
3. 遍历 ⟺ 特征值 1 是单重的。
4. 转动：每个纯音 eₖ 都是 U 的特征向量。
5. α 无理：只有 k = 0 不动，所以遍历。
6. 混合会消灭特征向量：谱变成连续的。

## 平均遍历定理

1. 冯·诺依曼：把 f、Uf、U²f……Uᴺ⁻¹f 平均。
2. 把 H 拆开：不变向量，和差 Ug − g。
3. 对不变向量，平均什么也不改。
4. 对 Ug − g，求和相消：(Uᴺg − g)/N → 0。
5. 所以平均 → 投影。遍历时就是 f 的均值。

## 外尔等分布

1. 外尔：点 nα mod 1 均匀铺满圆周。
2. 落在 [a, b] 里的比例趋于 b − a。
3. 每个纯音平均下来是 0：几何级数。
4. 有序和混沌，都写在一个算子的谱上。

## 结尾

1. 搅拌是混沌，作用在函数上却是等距。
2. 回归、遍历、混合：全是谱的事实。
3. 下一集，季终：广义函数。
