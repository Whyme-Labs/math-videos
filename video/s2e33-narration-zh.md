## 开场：狄拉克 δ

1. 物理学家最爱狄拉克 δ 函数 δ(x)。
2. 处处为零，只在一点有无穷高的尖峰。
3. 面积正好是 1：一个点电荷，一记锤击。
4. 只有一个问题：这样的函数不存在。
5. 只在一点非零，面积就是 0，不是 1。
6. 施瓦茨注意到：δ 总是出现在积分里。
7. 而 ∫ δ(x) φ(x) dx 永远等于 φ(0)。
8. 那就让 δ 当一个测量，而不是函数。

## 片头

1. 第二季，第三十三集。广义函数。

## 方块的极限

1. 试试方块：宽 1/n，高 n，面积 1。
2. 逐点看，除了一个点，处处趋于 0。
3. 在 L² 里它爆掉了：‖δₙ‖² = n。
4. 可拿任何光滑的 φ 去测，结果稳住了。
5. ∫ δₙ φ → φ(0)。测量值收敛。

## 试验函数与广义函数

1. 试验函数：光滑的鼓包，出了一个盒子就是 0。
2. 广义函数：试验函数上的连续线性泛函。
3. 每个函数 f 都是：φ ↦ ∫ f φ。
4. δ 也是：δ(φ) = φ(0)。
5. 测度也是，包括点质量。
6. 输入越小，对偶越大：D ⊂ L² ⊂ D′。

## 广义导数

1. 分部积分：∫ f′φ = −∫ f φ′。
2. 把它当定义：T′(φ) = −T(φ′)。
3. 从此每个广义函数都能求任意阶导数。
4. 阶跃 H：H′(φ) = −∫ φ′（0 到 ∞）= φ(0)。
5. 所以 H′ = δ。跳跃求导变成尖峰。
6. 极限和求导终于可以交换了。

## 撞钟（中文版）

1. 《礼记·学记》：“善待问者如撞钟。”
2. “叩之以小者则小鸣，叩之以大者则大鸣。”
3. 一记敲击就是 δ，钟声就是它的响应。
4. 敲多大，响多大：响应是线性的，可以叠加。

## 格林函数

1. 格林函数：先解一次 LG = δ。
2. 任何源 f 都是平移的点源叠起来的。
3. 所以 u = G ∗ f：把响应加起来。
4. 弦上：G(x, y) = min(x, y)(1 − max(x, y))。
5. 三维：G = 1/(4π|x|)，点电荷的电势。

## 弱形式与里斯

1. 泊松方程：−u″ = f，两端 u = 0。
2. 乘上试验函数 v 再积分：∫ u′v′ = ∫ f v。
3. a(u, v) = ∫ u′v′ 是 H¹₀ 上的内积。
4. v ↦ ∫ f v 有界，里斯给出唯一的 u。
5. 有限元：在帽子函数上解同一个方程。
6. 误差与帽子函数正交：又是投影。

## 本季回顾：测量

1. 这一季讲的是一个关于测量的故事。
2. 余向量测量箭头，里斯又把测量变回箭头。
3. 哈恩–巴拿赫：测量多到足以区分一切。
4. 库普曼：通过测量来研究混沌。
5. 一个函数，就是它回应测量的方式。
6. 回应得像函数，你就是函数：δ。
