## Cold open

1. We described numbers by how they behave. But what is the number two, actually?
2. Let's build numbers from the simplest thing there is: an empty box. Call it zero.
3. Put that empty box inside a new box. It holds one thing. Call it one.
4. A box holding both of those holds two things. Call it two.
5. Boxes inside boxes, built from nothing. But first we need rules for which boxes are allowed.

## Russell's paradox

1. The first idea, from Cantor's time: any property you can describe makes a set.
2. The set of even numbers. The set of all sets, which would even contain itself.
3. Now take the property of not containing yourself, and collect every such set into R.
4. Is R inside R? If it is, then it isn't. If it isn't, then it is.
5. Russell found this around 1901. In 1902 he wrote to Frege, whose book on arithmetic rested on exactly this idea.

## ZF: safe building rules

1. The fix: you may not collect everything with a property.
2. You may only carve a smaller set out of a set you already have, or build with a few fixed tools.
3. These rules are called ZF, after Zermelo and Fraenkel.
4. Carve Russell's set out of any box, and it lands outside that box. The paradox becomes a theorem: there is no set of all sets.

## von Neumann's numbers

1. Now build. Zero is the empty set.
2. The next of a set x is x together with x itself: x union the set of x.
3. So one holds zero. Two holds zero and one. Three holds zero, one and two.
4. Each number is the set of all the numbers before it, so three has exactly three elements.
5. Collect them all and Peano's five rules hold. That's the natural numbers, built from nothing.

## Zermelo's numbers

1. In 1908, Zermelo used a different next: just put x in one more box.
2. Zero, the box of zero, the box of that, and so on.
3. Both versions satisfy Peano's rules. So: is one an element of three?
4. Von Neumann's three says yes. Zermelo's three says no.

## Which is the real 3?

1. So which one is the real three? In 1965 the philosopher Paul Benacerraf asked exactly this.
2. Dedekind's theorem matches the two chains step by step, so all their arithmetic agrees.
3. What matters about three is where it sits: after two, before four. A number is what it does.
