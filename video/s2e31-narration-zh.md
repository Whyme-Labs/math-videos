## 开场：位置没有特征值

1. 把 [0, 1] 上的函数乘以 x。简单，线性。
2. x·f = λf 逼得 f 只能活在 x = λ 这一点。
3. 只在一点上非零的函数就是零。没有特征向量。
4. 在量子力学里，乘以 x 就是“位置”。
5. 教科书说：测量结果都是特征值。
6. 位置一个特征值都没有，探测器却天天在测它。
7. 在无穷维里，“特征值”本来就选错了。
8. 换成谱：让 T − λ 不可逆的那些 λ。

## 右移算子

1. 右移：S(x₁, x₂, …) = (0, x₁, x₂, …)。
2. 设 Sx = λx：λx₁ = 0，λx₂ = x₁，λx₃ = x₂……
3. 坐标一个接一个倒成 0：S 没有特征值。
4. 可 S 不是满射：没有谁被映到 e₁。
5. 单射却不满射，这在有限维里不可能。

## 谱

1. 换个问法：T − λ 可逆吗？不可逆，λ 就在谱里。
2. 失败有三种：不是单射，这就是特征值……
3. ……像稠密却不满，或者像根本不稠密。
4. |λ| > ‖T‖ 时，几何级数把 T − λ 逆了回来。
5. 所以 σ(T) 是闭集，在半径 ‖T‖ 的圆盘里。
6. 刘维尔定理：在 ℂ 上，σ(T) 永远不空。

## 两个例子

1. 右移：|λ| < 1 时，几何向量 v 在 ℓ² 里。
2. S − λ 的每个输出都和 v 垂直。
3. 所以 σ(S) 是整个闭单位圆盘，仍没有特征值。
4. 乘以 x：λ 不在 [0, 1] 里，1/(x − λ) 就是逆。
5. λ 在 [0, 1] 里，又高又窄的鼓包几乎解出 xf = λf。
6. ‖(M − λ)fₙ‖ ≤ 1/n：σ(M) = [0, 1]，全是连续谱。

## X 和 P 为何无界

1. 物理要 XP − PX = iħ。X 和 P 能有界吗？
2. 矩阵不行：XP − PX 的迹是 0，iħI 的不是。
3. 有界算子：归纳得 XPⁿ − PⁿX = n·iħ·Pⁿ⁻¹。
4. 取范数：对每个 n，nħ ≤ 2‖X‖‖P‖。不可能。
5. 所以 X 和 P 不能都有界。
6. 海林格–特普利茨：它们只能定义在稠密子空间上。

## 量子力学对照表

1. 对照表：状态是单位向量 ψ。
2. 可观测量是自伴算子，可能的结果是它的谱。
