```
To count forever you need a start and a "next". But those two rules also allow a loop, a merge, and a chain of ghost numbers you never reach.

Peano's five rules rule them out. The fifth one is induction, and it works like a line of dominoes.

Episode 2: <YouTube link>
```

**Thread** (4 posts):

1. `What's the least you could tell a machine so it counts forever? "Start at 0, and every number has a next" sounds like enough. It isn't. 🧵`
2. `Those two rules allow a loop (2 → 0, like a clock), a merge (3 → 2, stuck forever), and ghosts: a second chain you never reach by counting up from 0.`
3. `Peano (1889): 0 is nobody's next, so the loop breaks. Different numbers have different nexts, so the merge splits. And induction says everything is reached from 0 by taking next, so the ghosts go.`
4. `Dedekind proved in 1888 that any two systems obeying these rules are the same up to renaming. That's ℕ. Episode 2: <YouTube link>`
