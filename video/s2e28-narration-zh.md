## 开场：最近点之问

1. 在平面上，直线上离某点最近的点很好找。
2. 作一条垂线。误差和直线正交。
3. 有的空间没有最近点，差距一直缩小，永远到不了。
4. 现在看 [0, 1] 上所有平方可积的函数。
5. 录音片段、温度曲线、电子的波函数。
6. 取子空间：所有直线 a + b·x。
7. 有没有一条离 x² 最近的直线，误差还正交？
8. 有，只要同时有角度和完备性。今天讲希尔伯特空间。

## 片头

1. 第二季，第二十八集。希尔伯特空间。

## 光有内积不够

1. 光有内积还不够。
2. 在有限数列里，瞄准平面 ⟨x, y⟩ = 0。
3. 离 e₁ 最近的点要用上每一项，这里不允许。
4. 没有内积，球就有棱角：最近点不止一个。
5. 希尔伯特空间两样都有：内积，加上完备。

## 投影定理

1. 投影定理：闭凸集 C 里只有一个最近点。
2. 在 C 里取一串点 cₙ，离最小距离 d 越来越近。
3. 平行四边形法则：‖cₘ − cₙ‖² ≤ 2/n + 2/m。
4. 所以它们是柯西列，完备性给出极限 p。
5. 对子空间，误差 x − p 与它正交。
6. 所以每个闭子空间 M 都有 H = M ⊕ M⊥。

## 规矩（中文版）

1. 《孟子》：“不以规矩，不能成方圆。”
2. 规画圆，量的是长短。
3. 矩成直角，管的是垂直。
4. 希尔伯特空间规矩俱全：有范数，也有直角。

## 里斯表示定理

1. 里斯：每个连续泛函都是 ⟨x, y⟩，y 只有一个。
2. 把 φ 画成一叠平行的等值超平面。
3. 它的核是闭的，所以往核上作垂线 z。
4. y = z / ‖z‖² 横穿这叠平面，而且 ‖φ‖ = ‖y‖。
5. 例：f 在 [0, ½] 上的积分，就是 ⟨f, 1_[0,½]⟩。
6. H 就是自己的对偶。巴拿赫空间丢了它，现在回来了。

## 正交基、贝塞尔与帕塞瓦尔

1. 离 x² 最近的直线是 x − 1/6，误差平方 1/180。
2. 再一个一个加上正交单位方向 e₁、e₂、e₃。
3. 每一步重新投影，误差就缩小一点。
4. 贝塞尔：Σ |⟨x, eₙ⟩|² ≤ ‖x‖²，加起来不会超。
5. 完备性把级数加起来。帕塞瓦尔：正好相等。
6. 所以 x = Σ ⟨x, eₙ⟩ eₙ，是无穷多个影子之和。

## 只有一个 ℓ²

1. 每个可分的希尔伯特空间都有这样的基。
2. 读出坐标：x ↦ (⟨x, e₁⟩, ⟨x, e₂⟩, …)。
3. 这个映射保长度、保角度，落在 ℓ² 里。
4. 所以 L²[0, 1]、L²(ℝ)、量子态空间，都是 ℓ²。
5. 不用去造，只要描述：唯一的可分希尔伯特空间。
6. 附送：f(t) = t 加帕塞瓦尔，得到 Σ 1/n² = π²/6。
