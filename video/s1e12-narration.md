## Cold open: the girl with no room

1. After last night, the clerk of the infinite hotel is feeling unbeatable. A new sign goes up: no crowd too large.
2. At three in the morning one more bus pulls in. Every passenger's name tag is an infinite decimal, and every decimal between 0 and 1 is on board.
3. The clerk writes the list: room 0 gets this one, room 1 gets that one, all the way down.
4. A girl at the back reads the list. Her first digit differs from guest 0's first digit, her second from guest 1's second, and on down the line.
5. Her name is different from every name on the list. She has no room, and however the clerk reshuffles, she can do it again.

## The diagonal, close up

1. Write the list as a table of digits. Walk down the diagonal: guest 0's digit 0, guest 1's digit 1, guest 2's digit 2.
2. Change every one: write 5 unless the digit was 5, and then write 4. The new number differs from row n in place n, for every n.
3. Why only 4 and 5? A rule like add one could build 0.1999 repeating when 0.2 is already on the list: the same point, under its other name.
4. Shuffle the list any way you like. The diagonal changes, and a new girl walks out. Every list of real numbers misses one.

## Cantor's theorem: the party nobody hosts

1. The trick has nothing to do with decimals. Say every guest throws a party, and writes a guest list.
2. Some guests invite themselves. Now make one more list: everyone who did not invite themselves. Whose party is that?
3. If it's guest a's, then a is on it exactly when a isn't. No guest owns it. So a set always has more subsets than members.

## One trick, many costumes

1. The same table keeps coming back in costume. Rows of sets: is x in y? Flip the diagonal, and you get Russell's paradox.
2. Rows of sentences: this sentence is false. Rows of computer programs: does program n halt on input n?
3. Flip that diagonal and you get a program no checker can predict. Turing, 1936: no program can decide whether every program halts.

## Most numbers can never be named

1. One more costume. Every name, every formula, every program is a finite string of symbols, so they can all be listed.
2. So only countably many real numbers can ever be named. Give each one a tiny interval around it, and they cover almost nothing.
3. Throw a dart at the number line, and it lands on a number nobody will ever be able to name.
