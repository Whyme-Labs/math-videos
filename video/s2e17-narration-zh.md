## 开场：谷神星的失而复得

1. 1801 年元旦夜。皮亚齐看见一个在星星间移动的光点。
2. 他追了几个星期，它却钻进了太阳的光芒里。
3. 要再找到它，得从他的观测算出轨道。
4. 每次观测都有一点误差。没有轨道能全都对上。
5. 每一个猜测，总有地方对不上。
6. 24 岁的高斯说：找最不错的那条轨道。
7. 让偏差的平方和尽可能小。
8. 到了十二月，谷神星就在他说的地方。

## 片头

1. 第二季，第十七集。投影与最小二乘。

## 四个点，没有直线

1. 先看个小问题：四个点，一条直线。
2. 每个点都给出一条关于截距和斜率的方程。
3. 前两个点定下直线：从 1 出发，斜率 2。
4. 第三个点却说 1 + 4 = 4。不对。
5. 四个方程，两个未知数。没有精确解。

## 最好的拟合是影子

1. 换个看法：四个高度，合起来是一支箭头 b。
2. 模型能画出的每条直线，都落在一个平面上。
3. b 浮在平面上方。所以怎么都对不上。
4. 从正上方打一束光。b 投下影子 p。
5. 误差 e = b − p 笔直地竖着。
6. 最好的拟合，就是这个影子。

## 为什么影子最近

1. 为什么影子最近？任取平面上另一点 u。
2. 从 b 到 u：先走误差，再沿平面走一步。
3. 这两段成直角。勾股定理。
4. 所以 ‖b − u‖² = ‖e‖² + ‖p − u‖²。不会更小。
5. “最近”恰好就是：误差垂直于平面。

## 投影到一条直线

1. 先看最简单的情形：平面只是一条沿 a 的直线。
2. b 的影子是 a 的某个倍数：p = x a。
3. 误差 b − x a 必须垂直于 a。
4. 所以 a · b − x a · a = 0。解出 x。
5. x = a·b / a·a。影子只要两次点积。

## 法方程

1. 回到那四个点。垂直于平面，意思是……
2. ……误差同时垂直于 A 的两列。
3. 这就是 AᵀA x = Aᵀb：法方程。
4. 解出来：截距 1.5，斜率 1。直线 y = 1.5 + t。
5. 四个偏差：−½、½、½、−½。正好抵消。
6. 偏差平方和是 1。没有直线能更好。

## 投影映射 P

1. 造影子这件事本身是一个映射，叫它 P。
2. 影子的影子一动不动：P² = P。
3. P 扔掉的正是误差，也就是 I − P。
4. 每个 b 都拆成两份：拟合加误差，互成直角。
5. 用 A 的列来写：P = A(AᵀA)⁻¹Aᵀ。

## 郭守敬的高表与景符（中文版）

1. 元代郭守敬测日影，立起四丈高表。
2. 表越高，影子越长，读数的误差就相对越小。
3. 他又造景符，让模糊的影端变成一个清楚的亮点。
4. 冬至前后多日测影，前后对照，求出冬至的时刻。

## 格拉姆–施密特与 QR

1. 影子需要一组互相垂直的基。看怎么造。
2. 第一支箭头留下，缩放到长度 1。
3. 第二支：剥掉它在第一支上的影子。
4. 剩下的部分垂直于第一支。再缩放。
5. 第三支：剥掉它在前两支平面上的影子。
6. 格拉姆–施密特。剥下的量填成一个三角：A = QR。

## 勒让德多项式

1. 对函数也这么做：[−1, 1] 上的 1、x、x²、x³。
2. 每一个都和前面的剥一遍。
3. 得到勒让德多项式，每个多一次起伏。
4. x² 最好的直线近似是常数 ⅓，误差是 ⅔ P₂。
