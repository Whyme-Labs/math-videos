## 开场：1, 0, 1, 0, … 的极限

1. 1, 0, 1, 0, 1, 0, … 的极限是多少？
2. 微积分说：没有。它永远定不下来。
3. 可要是非得给一个数，你会说 ½。
4. 1, 0, 0, 1, 0, 0, … 呢？你会说 ⅓。
5. 能不能把它正式化，对每个有界数列都成立？
6. 巴拿赫在 1932 年证明了：能。
7. 可没人写出过一个，以后也不会有人写出来。
8. 今天：保证测量够用的那个定理。

## 片头

1. 第二季，第二十五集。哈恩–巴拿赫定理。

## 用基来延拓

1. 子空间 M 上有个测量 f，想把它延拓到 X。
2. 这里 M 是一条直线，f 读出沿线的位置。
3. 任何 F(x, y) = x + c·y 在 M 上都和 f 一样。
4. 在无限维里，哈默尔基也能这样做。
5. 可它造出来的延拓，通常是怪物。
6. 我们要的是连续的延拓：范数不变大。

## 一步延拓

1. 哈恩–巴拿赫：f 总能保持范数不变地延拓。
2. 加一个方向 z，要选的只有 c = F(z)。
3. 条件把 c 夹在一个上确界和一个下确界之间。
4. 三角不等式保证：中间的空隙不会合上。
5. 在 ℓ¹ 的菱形上，−1 到 1 之间的 c 都行。
6. 在圆盘上，只有 c = 0：只有一条切线。

## 佐恩引理

1. 一次加一个方向，可 X 的方向无穷无尽。
2. 把部分延拓排好序，每条链都有上界。
3. 佐恩引理给出一个最大的，它必定是整个 X。
4. 佐恩引理就是换了装的选择公理。记住这一点。

## 赋范泛函

1. 收获来了。随便取一个向量，比如 x₀ = (3, −4)。
2. 有个范数为 1 的 f，读出它的全长：f(x₀) = ‖x₀‖。
3. 在 ℓ² 里，f = (3/5, −4/5)，读数 5。
4. 在 ℓ¹ 里，f = (1, −1)，读数 7。
5. 所以范数就是最好的读数：‖x‖ = max |f(x)|。
6. 而且只要 x ≠ y，总有测量能把它们分开。

## 分离凸集、支持向量机与线性规划

1. 几何形式：一个凸集，和它外面的一个点。
2. 一个超平面滑进两者之间：它是 f 的等值面。
3. 闭凸集就是包住它的所有半平面的交。
4. 不凸就不行：一个圆周和它的圆心。
5. 过圆心的每条直线都会切到圆周。
6. 支持向量机找的，就是最宽的那条缝。
7. 线性规划里，价格 ⅖ 和 ⅕ 证明了最优值是 14/5。

## 鸿沟（中文版）

1. 公元前 203 年，楚汉相争，约定以鸿沟为界。
2. 《史记》：“割鸿沟以西者为汉，鸿沟而东者为楚。”
3. 两边的地盘各自连成一片，一条线就能分开。
4. 分离定理说：两个凸集之间，总有一条鸿沟。

## 巴拿赫极限

1. 回到 1, 0, 1, 0, …，把前 n 项取平均。
2. 让 p(x) 等于这些平均值反复能达到的最高值。
3. 哈恩–巴拿赫把 lim 延拓到 p 之下：巴拿赫极限 L。
4. L 不在乎平移，所以 L(x) + L(Sx) = 1。
5. 所以 L(x) = ½；1, 0, 0, 1, 0, 0, … 得 ⅓。
6. 可 L 要靠佐恩引理。它永远不会有公式。
