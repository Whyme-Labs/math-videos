## 开场：免费午餐与传送带

1. 线性代数最好的免费午餐：方程和未知数一样多。
2. 只要 Ax = 0 只有零解，每个 b 都有解。
3. 现在拿一排无穷多的格子。
4. 一台机器把每个数往右挪一格。
5. 什么都没丢：从输出能读回输入。
6. 可 1, 0, 0, … 永远出不来：第一格总是 0。
7. 十九集以来，每个证明都用到了维数有限。
8. 今天，五个熟悉的结论一一倒下。

## 新的空间

1. 新的空间：无穷数列，比如 (1, ½, ⅓, …)。
2. ℓ²：平方加起来有限的数列。
3. 它的轴 e₁ = (1, 0, 0, …)、e₂、e₃……看着眼熟。
4. 还有 [0, 1] 上的函数，用最高点量大小。
5. 一本账记下我们丢了什么。

## 第一项损失：移位

1. 第一项损失。方阵一对一，就一定是满射。
2. 把移位截成 n 格：最后一个数掉出去。
3. 让 n 变大，尽头跑远了，再没有数掉出去。
4. 先右移再左移：回到原处，LS = I。
5. 先左移再右移：第一格丢了，SL ≠ I。

## 第二项损失：斜率爆炸的波纹

1. 第二项损失。每个矩阵都有最大的伸缩 σ₁。
2. 现在对 f = ε sin(x/ε²) 求导。
3. ε 越小，图像越贴近横轴。
4. 斜率却像 1/ε 一样涨，没有上限。
5. 一个线性映射把很小变成很大。σ₁ 不存在。

## 第三项损失：有限和填不完

1. 第三项损失。每个向量应是基向量的有限和。
2. 取 (1, ½, ⅓, ¼, …)，平方和是 π²/6。
3. e₁、e₂……的有限和从左边一格格填进去。
4. 到第 10 格还差 0.31，到第 1000 格还差 0.03。
5. 永远填不完。我们需要无穷和，也就需要极限。

## 第四项损失：单位球不紧

1. 第四项损失。三维球面上的点，总会在某处聚拢。
2. 在 ℓ² 里，轴 e₁、e₂、e₃……长度都是 1。
3. 任何两个都相距 √2，谁也不靠近谁。
4. 没有子列会收敛。单位球不是紧的。
5. 于是在球面上求最大值可能落空。
6. 这里 1 − 1/k 一直往 1 爬，永远到不了。

## 《墨经》论穷（中文版）

1. 《墨经》给“有穷”和“无穷”下过定义。
2. “穷，或不容尺，有穷；莫不容尺，无穷也。”
3. 量到某处，再放不下一把尺子，就是有穷。
4. 处处都还能再放一把尺子，就是无穷。

## 第五项损失：没有特征向量

1. 第五项损失。在 ℂ 上，每个矩阵都有特征向量。
2. 把每个函数乘以 x。假设 x·f = λf。
3. 那么 f 除了 λ 处都是 0，由连续性 f = 0。
4. 在 n 个点上取样，它是对角的，特征向量是尖刺。
5. n 越大，尖刺越细，最后什么都不剩。没有特征向量。
6. 宽 1/n 的小帐篷很接近：只差 1/(4n)。
